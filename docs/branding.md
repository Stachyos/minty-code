# Minty Code 猫娘图案

图案使用内置 imagegen 工具生成，透明 PNG 文件保存在 `frontend/public/images/minty-catgirl.png`，当前用于侧边栏 Logo 和浏览器图标。页面整体保持黑白极简，薄荷绿只用于选中态、发送键与状态点等点缀。

## 生成提示词

Use case: logo-brand. Create one original cute mint-colored anime catgirl mascot logo for a personal coding assistant. A friendly chibi head-and-shoulders portrait facing the viewer, mint-green short fluffy hair, clearly visible soft cat ears with pale pink inner ears, large expressive dark teal eyes, tiny warm smile, subtle blush, and a simple cream collar with a small mint bow. Polished Japanese kawaii illustration, clean confident dark sage outlines, simplified shapes that remain readable as a 48px app logo, gentle cel shading, restrained mint / cream / blush palette. Centered balanced square composition, face and ears occupy most of the image with a narrow clean margin, all ears and hair fully within frame. Wholesome mascot, no lettering, no watermark, no text or decorative badge, no plant, no flowerpot. Output an isolated character with genuine transparent background.
